# Design source

Drop Figma screen exports here (PNG @2x preferred), one file per prototype screen.
Suggested naming: `01-home.png`, `02-auctions-list.png`, `03-auction-detail.png`, …

Also useful if you can export them:
- `tokens.json` — Figma variables (colors, spacing, radius) export
- Font files, if the design uses a non-Google font

This folder is only a working reference — it is not bundled into the app.
